# Vereinsverwaltung

## Info

Zum Start der Anwendung:

**Backend:**
```bash
cd backend
mvn clean install
```

**Frontend:**
```bash
cd frontend
mvn clean install
```

**Launcher (startet Backend + Frontend):**
```bash
cd launcher
javac src/Main.java
java -cp src Main
```

Wichtig: Die Befehle müssen aus dem Ordner `launcher` ausgeführt werden, nicht aus `launcher/src`.

---

## Beschreibung

Eine Java-basierte Desktop-Anwendung zur Verwaltung von Vereinen, Mitgliedern, Gruppen, Rollen und Veranstaltungen.  
Entwickelt mit **Spring Boot** im Backend und **JavaFX** im Frontend.
